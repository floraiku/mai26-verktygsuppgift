# Git- och verktygsövning

Detta är en övning där jag tränar på terminal, VS Code och Git.
Jag skapar mappar och filer, versionshanterar med Git och pushar till GitHub.

## Git-kommandon som använts

- git init – skapar ett nytt repository
- git status – visar vilka filer som ändrats
- git add – lägger till filändringar inför commit
- git commit -m "meddelande" – sparar en version i historiken
- git log – visar tidigare commits
- git remote – kopplar till en server, t.ex. GitHub
- git branch – hanterar branches
- git push – skickar upp ändringar till GitHub
- git pull – hämtar ändringar från GitHub

## Vad är ett repository, en commit och versionshistorik?

Ett repository är en mapp som Git håller koll på, där alla ändringar sparas över tid.
En commit är en sparad version av projektet vid en viss tidpunkt, med ett meddelande som beskriver vad som ändrats.
Versionshistorik är den samlade listan av alla commits, som gör att man kan se och gå tillbaka till tidigare versioner av projektet.
